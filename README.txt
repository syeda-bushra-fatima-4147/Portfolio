HOW TO PREVIEW

HOW TO PUBLISH WITH GITHUB PAGES
1. Sign in at https://github.com/
2. Create a new PUBLIC repository named bushra-portfolio.
3. Upload index.html, style.css, and script.js to the repository root (and optionally the resume files).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for deployment. The public URL will look like https://YOUR-USERNAME.github.io/bushra-portfolio/ . Copy the actual URL shown in Settings > Pages.
